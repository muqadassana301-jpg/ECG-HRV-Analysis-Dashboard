 ECG-HRV-Analysis-Dashboard
ECG and HRV Analysis Dashboard using Python for time-domain, frequency-domain, and non-linear biomedical signal analysis.
ECG & HRV Analysis Dashboard (PyQt5)

A desktop application for ECG signal processing and Heart Rate Variability (HRV) analysis.

Features:
 Upload ECG files (DAT, HEA, ZIP)
 ignal filtering and preprocessing
 R-peak detection
 RR interval extraction
 Time-domain HRV metrics
 Frequency-domain analysis (PSD)
 Poincaré plot (nonlinear analysis)
 PDF report export

Installation
pip install -r requirements.txt

Run
python hrv_dashboard.py

Note
Ensure correct ECG format and sampling rate for accurate results.
